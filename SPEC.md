# ЭФИР — проектный бриф (единый источник правды для всех агентов)

Портфолио-кейс №3 из 8 для демонстрации на собеседовании (агентство Brain Look, Воронеж).
Должен визуально и технически радикально отличаться от кейсов №1 (ЧЕРНОЗЁМ — тёмный
ресторан, GSAP split-text) и №2 (FORMA — светлый fashion-минимализм, 3D-ткань).

## Концепция
Нишевый парфюмерный дом **ЭФИР** (один флакон-хит, три варианта аромата). Полностью
3D-витрина: настоящий Three.js флакон (LatheGeometry, стеклянный материал), который
можно **тянуть мышью, чтобы вращать** (с инерцией), и который **реагирует на скролл**
(камера приближается/меняет ракурс по мере прокрутки закреплённой секции).

## Технологии (обязательно)
- GSAP 3.12.5 + ScrollTrigger (cdnjs, те же версии что в кейсах 1 и 2)
- Lenis 1.1.14 (smooth scroll)
- Three.js r160 (`https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js`)
- Google Fonts: **Golos Text** (вес 400/500/600/700/900) — единственный шрифт, без серифа.
  Не используем Fraunces/Bodoni Moda/Cormorant/PT Serif/Unbounded/Inter — это уже было
  в кейсах 1 и 2, нужен новый почерк.
- Никаких упоминаний motionsites.ai в коде/комментариях.

## Структура страницы (id/классы — обязательны, по ним работают все агенты)

1. `#preloader .preloader` — марка "ЭФИР", тонкая линия-прогресс.
2. `header#header .header` — `.header__logo` ("ЭФИР"), `.header__nav` (ссылки на `#lab`,
   `#notes`, `#variants`, `#about`), `.header__cta` (кнопка "Где купить").
3. `section#lab .lab` — **закреплённая (pinned) 3D-секция**, высота ~280vh.
   - `.lab__canvas-wrap` → `<canvas id="bottleCanvas">` на весь vh.
   - Три блока подписи `.lab__state[data-state="0"|"1"|"2"]` — JS переключает
     `.is-active` по прогрессу скролла (аналогично пин-секции "Образы" в кейсе FORMA,
     но двигает 3D-камеру, а не меняет плоские картинки).
   - `.lab__hint` — подсказка "Потяните, чтобы повернуть флакон".
4. `.marquee` — бегущая строка (тезисы бренда).
5. `section#notes .notes` — три колонки `.notes__col` (верхние/средние/базовые ноты),
   в каждой — `.notes__title` + список `.notes__item` (название + короткое описание).
6. `section#ratings .ratings` — три шкалы-полосы `.rating__item` (не кольца как в FORMA,
   не голые цифры как в ЧЕРНОЗЁМ!): `.rating__label`, `.rating__bar` (заполняется при
   скролле), `.rating__value` (число %). Параметры: интенсивность, стойкость, шлейф.
7. `section#variants .variants` — три карточки `.variant[data-variant="amber|dusk|salt"]`.
   Клик вызывает глобальную функцию `window.bottleScene.setVariant(name)` (меняет цвет
   жидкости во флаконе в 3D-сцене, даже если секция `#lab` сейчас не в зоне видимости).
8. `section#about .about` — текст-философия + статичное изображение (текстура/ингредиенты).
9. `section#cta .cta` — минимальная форма "Узнать о запуске" (email, валидация, success-стейт).
10. `footer .footer` — гигантский wordmark-аутлайн "ЭФИР" (как в кейсах 1 и 2, но другим
    шрифтом — Golos Text, не Unbounded/Bodoni).

## Контракт 3D-сцены (для агента, который пишет `bottle-scene.js`)
Файл `bottle-scene.js`, без модулей (обычный `<script>`, UMD-стиль three.min.js уже
загружен глобально как `THREE`). Экспортирует одну глобальную функцию:

```js
window.initBottleScene = function(canvasEl) {
  // ... создаёт сцену, рендерит в canvasEl ...
  return {
    setVariant(name),       // 'amber' | 'dusk' | 'salt' — плавно тонирует жидкость
    setScrollProgress(p),   // p: 0..1 — двигает камеру/масштаб по трём состояниям
    destroy()
  };
};
```
Требования к сцене:
- Флакон — `THREE.LatheGeometry` (профиль: широкое основание → сужение к "плечикам" →
  тонкое горлышко → крышка). Стекло — `MeshPhysicalMaterial` (transmission, roughness
  низкий, ior~1.5). Внутри — отдельный меш чуть меньше по размеру = "жидкость"
  (непрозрачный/полупрозрачный цветной материал, цвет меняется через `setVariant`).
  Крышка/колпачок — отдельный меш, глухой материал цвета `--gold`.
- Свет: 2–3 источника (key + rim + мягкий ambient), что-то под ногами (плоскость-пол
  с полупрозрачным тёмным материалом для мягкого отражения/тени, не обязательно
  честный reflection-пасс — approximation нормально).
- Drag-to-rotate: pointerdown/pointermove/pointerup на canvas, вращение по Y (и слегка
  по X), с инерцией после отпускания (плавное затухание скорости). Должно работать и
  тач-событиями (pointer events покрывают оба случая).
- `setScrollProgress(p)` трактует 0→0.33 как "общий план" (камера дальше), 0.33→0.66
  как "приближение к горлышку/крышке" (camera.position.z уменьшается, возможно lookAt
  сдвигается к верхней части флакона), 0.66→1 как "план на жидкость/основание".
  Плавная интерполяция (lerp), не резкие скачки.
- Деградация: если `prefers-reduced-motion: reduce` — сцена рисуется статично (без
  авто-вращения и инерции), drag всё ещё можно оставить. Если `navigator.hardwareConcurrency <= 4`
  — упростить (меньше сегментов в geometry, отключить тени).
- Код должен быть устойчив к повторной инициализации и не быть "сырым": проверка на
  существование canvasEl, обработка resize.

## Контракт контента (для агента-копирайтера)
Нужен файл `COPY.md` со следующими пронумерованными блоками (простой текст, без HTML),
на русском языке, в голосе нишевого бренда ароматов — сдержанно, образно, без клише
("нотки", "шлейф" уместны, но без пафоса в духе "роскошь для избранных"):

1. Заголовок хиро (коротко, 2-4 слова, обыгрывает слово "эфир"/воздух/невидимое)
2. Подзаголовок хиро (1 предложение)
3. Текст подсказки для drag (если хотите заменить "Потяните, чтобы повернуть флакон")
4. Текст трёх состояний `.lab__state` (0: общий план флакона — 1 фраза; 1: про крышку/
   мастерство — 1-2 фразы; 2: про состав/базу — 1-2 фразы)
5. Фразы для бегущей строки (4-6 коротких тезисов через точку)
6. Три колонки нот (верхние/средние/базовые), в каждой — заголовок колонки + 3
   ингредиента (название + 3-6 слов описания)
7. Три характеристики для `.ratings` (интенсивность/стойкость/шлейф) — название + число
   0-100 + одна строка пояснения
8. Три варианта аромата (Янтарь/Сумрак/Соль) — название, 1-2 предложения описания,
   цена (любая правдоподобная цифра в рублях)
9. Текст секции "О бренде" (2-3 абзаца, философия: почему один флакон, а не линейка)
10. Текст CTA-секции (заголовок + подпись + текст кнопки)
11. Текст футера (контакты-заглушки, копирайт)

## Контракт вёрстки/CSS (для агента-дизайнера)
Строит `index.html` (структура по разделу "Структура страницы" выше, с placeholder-
текстом там, где копирайт ещё не готов — его потом заменит интегратор) и `styles.css`
(токены палитры выше, Golos Text, адаптив, анимации-классы `.reveal-up` и т.п. как в
кейсах 1-2 для совместимости со общим script.js). Курсор — другой стиль чем в кейсах
1 и 2: маленькая точка + тонкое кольцо, которое медленно вращается (не заливается
полностью при ховере, а растягивается в овал). Никаких заимствований компоновки из
ЧЕРНОЗЁМ/FORMA 1:1 — макет должен выглядеть как отдельный бренд.
