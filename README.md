# ЭФИР — ВУАЛЬ

Демо-сайт парфюмерного бренда с 3D-витриной флакона в браузере (Three.js) — учебный проект для портфолио.

Стек: HTML / CSS / JavaScript, Three.js, GSAP + ScrollTrigger, Lenis (плавный скролл).

**Живая демка:** https://levalnik0.github.io/efir-parfum/

3D-модель флакона: «Perfume Bottle» — Michaela Blanchfield, Sketchfab, CC BY 4.0.
